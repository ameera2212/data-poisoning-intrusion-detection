
# Experimental Results

This folder contains the results of the intrusion detection experiments, including baseline performance, label-flipping attacks at 5%, 10%, and 20%, and defence evaluation.

- model_comparison.csv: Performance metrics for all models.
- accuracy_comparison.png: Model accuracy comparison.
- f1_comparison.png: Model F1-score comparison.
- defence_effectiveness.png: Poisoned versus defended model accuracy.
